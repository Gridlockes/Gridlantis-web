Before you ask

Straight answers

Do I own the code and the accounts?

Yes. Source files, hosting and any third-party accounts are registered to you or transferred to you at handover. You can hire anyone you like to work on it afterwards.

What if I don't know what I need?

That's normal, and it's what the first call is for. Describe the symptom, "invoices take me all Sunday," and the scope gets written from there.

Can you work with the tools we already use?

Usually. If a tool has a public API (Application Programming Interface, the connection point software vendors expose for other programs), it can generally be wired in. If it doesn't, you'll be told before you're quoted, not after.

How long does a typical build take?

A single landing page is measured in days. A multi-page site or a working bot is usually two to four weeks. A dashboard depends entirely on how tidy the data behind it is, which is something the first call establishes.

What happens if something breaks after handover?

Anything that was broken on delivery gets fixed at no cost. Changes you want later are either covered by a retainer or quoted as a small fixed job.
